# Bachelor Student Projects

## Context

These bachelor projects are part of a larger PhD research project focused on creating an **AI-supported cloud laboratory platform for education**.

The main goal of the PhD is to design and evaluate a self-hosted cloud environment where:

- Teachers can create practical cloud computing laboratories
- Students can access and complete those laboratories
- The platform can evaluate student progress based on their interactions and achievements
- Learning analytics can help teachers understand student difficulties
- Future AI-supported mechanisms can provide adaptive feedback and support

The platform will use **OpenStack** as the cloud environment. OpenStack allows the creation and management of cloud resources such as:

- Virtual machines
- Networks
- Subnets
- Routers
- Security groups
- Images
- Storage resources
- User projects and roles

Instead of depending only on commercial public cloud providers such as AWS, Azure, or Google Cloud, this research explores how universities can use self-hosted open-source cloud infrastructure for practical cloud computing education.

These bachelor projects will contribute to the first working version of the platform.
